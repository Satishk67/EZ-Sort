# EZ Sort

EZ Sort is an interactive web application designed to help users learn, visualize, and practice various sorting algorithms. The platform provides algorithm descriptions, code samples, practice questions, and user authentication for personalized features.

## Features

- 📊 **Algorithm Visualizations:** See how popular sorting algorithms work step-by-step.
- 📝 **Detailed Descriptions:** Learn the theory, time and space complexities, and real-world applications.
- 💻 **Code Samples:** Access clean, readable code for each algorithm.
- ❓ **Practice Questions:** Test your understanding with curated questions.
- 🔒 **User Authentication:** Sign in to unlock advanced features and track your progress.
- 👤 **User Dashboard:** View your profile and access personalized content.

## Technologies Used

- **React** (Vite)
- **Clerk** for authentication
- **CSS** for styling

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Satishk67/EZ-Sort.git
   cd EZ-Sort
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   - Create a `.env` file in the root directory.
   - Add your Clerk publishable key:
     ```
     VITE_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
     ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open in browser:**
   - Visit [http://localhost:5173](http://localhost:5173) (or the port shown in your terminal).
